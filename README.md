## No que estou trabalhando

- **Desenvolvimento com IA e agentes com foco em mobile:** uso o Claude no terminal em um sistema de fábrica agêntica, crio skills de desenvolvimento com loop de pesquisa → desenvolvimento → teste → review e ajudo a melhorar o harness do projeto.
- **Apps nativos:** iOS com SwiftUI (MVVM + clean architecture) e Android com Kotlin e Jetpack Compose.
- **Back-end com Java:** estudos e projetos acadêmicos com Spring e microsserviços.
